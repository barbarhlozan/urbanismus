Press kit

Pieces drawn by the game's own code, for banners and the itch.io page: the twin church (after Skoky), houses, trees, chat bubbles, and a village scene. All at one scale, so they fit together. Each can be saved as SVG or as a transparent PNG (?scale= px per unit, default 10; ?line= pen weight, default 2.2; ?scheme= 0–3, default Countryside; ?rot= 0–3). tools/press-kit.mjs saves them all to press/.
