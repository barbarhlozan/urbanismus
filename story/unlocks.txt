# What can be built when a town starts. The story can change it as it goes,
# with the same two commands in a branch:  unlock station
#
#   lock name      take it out of the Build menu (and out of Turn into…)
#   unlock name    put it back
#
# Read top to bottom: the last line that matches wins. Anything not locked
# is open. Case, accents, spaces, '-' and '.' don't matter in names (Národní
# výbor, narodni-vybor and narodni_vybor are the same).
#
# ---------- All the names ----------
#
# Everything
#   all                  every building and network tool (not the buttons at the
#                        top, nor traffic)
#
# Build menu groups (by name or id)
#   doprava, transport                Road, Lane, Footpath, Railway, the stations,
#                                     Bus stop
#   bydleni, housing                  House, Apartments, Block
#   obcanska_vybavenost, amenities    shops, pubs, offices, services, school,
#                                     House of culture, Swimming pool, Cemetery
#   vyroba, work                      Workshop, Works, Factory, Plant, the mines,
#                                     the farms
#   prostranstvi, spaces              parks and squares
#   pamatky, heritage, landmarks      Chapel, Church, Town hall, Memorial, Castle,
#                                     Tower, Stadium
#   zones                             bydleni + vyroba
#   public                            obcanska_vybavenost + prostranstvi
#
# Network tools
#   road
#   lane
#   footpath             (no footpath: no new streets with sidewalks either)
#   railway
#
# Shared names (tags) – each covers several things at once
#   residential          every home: house, apartments, block
#   business             jednota, hospoda, obchodni_dum, tuzex, narodni_vybor,
#                        posta, hotel
#   shop, pub, office, hotel
#   industrial           workshops, works, factory, plants and the mines
#   mine                 pit, colliery, deep_mine
#   farm                 farmstead, jzd, statni_statek
#   services             fire_station, police, health_centre, clinic, hospital,
#                        service_centre, school
#   fire, police, health, school
#   park                 every park, and the swimming pool
#   square               every square
#   heritage             every landmark, and culture_house too
#
# Things to build, by group. The name (as in the Build menu) covers all its
# sizes; the ids after it each name one size.
#   Doprava
#     station            station, station_main, stop
#     bus_stop           bus_stop
#   Bydlení
#     house              house, house_wide
#     apartments         apartments, apartments_wide
#     block              block, block_wide
#   Občanská vybavenost
#     jednota            jednota, jednota_wide
#     hospoda            hospoda, hospoda_wide
#     obchodni_dum       store, store_wide
#     tuzex              tuzex
#     narodni_vybor      office, office_wide, office_tower, office_tower_wide
#     posta              post_office
#     hotel              hotel, hotel_wide
#     fire_station       fire_house, fire_station, fire_station_large
#     police_post        police
#     health_centre      health_centre
#     polyclinic         clinic
#     hospital           hospital
#     service_centre     service_centre
#     school             school
#     house_of_culture   culture_house
#     swimming_pool      pool
#     cemetery           cemetery
#   Výroba
#     workshop           workshop, workshop_medium, workshop_large
#     works              works, works_medium
#     factory            factory
#     plant              plant_small, plant_medium, plant
#     pit                pit
#     colliery           colliery
#     deep_mine          deep_mine
#     farmstead          farmstead
#     jzd                jzd
#     statni_statek      state_farm
#   Prostranství
#     green              green
#     garden_park        garden_park
#     pavilion_park      pavilion_park
#     meadow             meadow
#     pond_park          pond_park
#     city_park          city_park
#     plaza              plaza
#     fountain_square    fountain_square, fountain_square_large
#     shopping_precinct  precinct, precinct_large
#     monument_square    monument_square
#     market_square      market_square
#     bus_station        bus_station
#     grand_square       grand_square
#     parade_square      parade_square
#   Památky
#     chapel             chapel
#     church             church
#     town_hall          town_hall, town_hall_small, town_hall_large
#     memorial           memorial
#     castle             castle
#     tower              tv_tower
#     stadium            stadium
#
# The buttons at the top (`all` leaves them be)
#   chronicle            the book by the town's name (it keeps writing while hidden)
#   photo                photo mode (and its key)
#   terrain              contour lines
#   colors               the Colors menu
#   assets
#   debug
#   export
#   import
#   new_map
#   fullscreen
#   controls             all of the buttons above
#
# Traffic (`all` leaves it be)
#   cars                 nobody drives: people walk, cycle or take the bus or
#                        train instead; no visitors or commuters come by car;
#                        car parks stand empty
#   trucks               industry keeps no trucks, and no deliveries come in
#   buses                no buses come (bus stops stay, empty)
#   vehicles             all three
#
# ------------------------------------
#
# And the colour scheme the game starts in:
#   scheme Blue pen        (or Black pen, Night, Countryside; a number from 1;
#                           custom; or three colours: scheme #ebe7dd #3e12b6 #9b9486
#                           – background, main, detail)
# It's put on whenever this line changes. While `colors` is locked it's put on
# every time; otherwise a scheme the player picks in the Colors menu stays.
#
# Full list and examples: story/README.md
#

# Jednota and a chapel, and no panel blocks until the story says so:

#   lock all

#   unlock footpath
#   unlock residential
#   unlock jednota
#   unlock chapel
#   lock block
#
# A finished game might hide what's only for making it:
#
#   lock debug
#   lock assets
#
